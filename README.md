# Abdulaziz Portfolio

Next.js App Router, React, TypeScript, Tailwind CSS va Framer Motion asosidagi shaxsiy portfolio.

## Ishga tushirish

```bash
bun install
bun run dev
```

Loyiha `http://localhost:3000` manzilida ochiladi.

## Tekshirish

```bash
bun run lint
bun run build
```

## Muhit sozlamalari

SEO canonical va sitemap uchun production domenini kiriting:

```bash
NEXT_PUBLIC_SITE_URL=https://example.uz
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```
